# Fibe (formerly EarlySalary)

> Fibe is a digital consumer lending platform in India (founded 2015 as EarlySalary, headquartered in Pune) offering instant personal loans up to Rs 10 lakh, loans against mutual funds, fixed deposits, a co-branded Fibe Axis Bank credit card, insurance, and purpose-driven (BNPL) financing. As of March 2026 it reports 48,000+ crore disbursed across 9.8M loans to 3.3M customers. Fibe runs a live, OAuth-protected Model Context Protocol (MCP) server so AI agents can read loan/eligibility data and initiate loan applications.

## Agent / MCP surface
- [Fibe MCP server](https://www.fibe.in/api/mcp): OAuth-protected JSON-RPC 2.0 MCP endpoint (scopes loan.read, loan.apply)
- [MCP documentation](https://www.fibe.in/mcp/): advertised service documentation for the MCP server
- [OAuth authorization-server metadata](https://www.fibe.in/.well-known/oauth-authorization-server): RFC 8414
- [OAuth protected-resource metadata](https://www.fibe.in/.well-known/oauth-protected-resource): RFC 9728
